# 图表选择与阅读

**最新展示原则：用两张并排柱状图讲清核心结论。** 左图比较C0/C1/C2错误回答率，右图比较C2/C3；纵轴统一0–100%。森林图及完整区间表移到PDF的统计补充。

错误回答率 = 错误数 /（正确数＋错误数＋弃答数）。正确与明确弃答均不计入错误分子，但留在每组719的分母中。这本来就是现有数值的计算口径，未把旧数据重新评分。按最终答案字段判分，不表示弃答解释中的每句话已验证为真。

本次只调整表达方式；冻结数据、评分、分析结果及两人署名保持不变。图形数据和报告图片由 `visualize_results.R` 生成；PPT 使用可编辑图表和热力表格。

|要回答的问题|图表|如何阅读|
|---|---|---|
|不同提示下出错有多少？|主展示：两张柱状图|柱高是样本错误回答率；直接标百分比与百分点差，弃答不计错。不同条件不是时间阶段，不画连续曲线。|
|效应差的估计有多不确定？|PDF统计补充：森林图＋95%区间|横轴为前一条件减后一条件的百分点差；0为无差异，左边为错误较少。横线是按题目聚类的bootstrap区间。不是单个模型回答的置信度。|
|正确、错误和弃答分别占多少？|100%堆叠条形图|每组完整配对分母均为719；绿色正确，橙色错误，灰色弃答。弃答单列，不默认算错误或给半分。标签四舍五入可能不恰好加到100%。|
|同一题在C2与C3下如何改变？|3×3热力图|行是C2、列是C3，颜色和数字表示配对数量，九格合计719。共同色阶0–228；不是按行归一化的概率，也不是先后对话。144错误→弃答与5错误→正确分开呈现。|
|AI核验发现哪种弃答最常见？|水平条形图|长标签适合横向排列；比较同一144组定向样本内的数量。不是对全部模型回答的抽样发生率估计。|
|原主分析发生了多少次正确改错或真正纠错？|计数柱状图|各图分别使用154个初始正确或322个初始错误单元，分母不能混用。相关配对效应及区间保留在文字中。|
|数学补充各条件答对多少？|PDF用点图，PPT用计数柱状图|均表示71单元的描述性计数。条件是类别，不能连成时间趋势。数学部分没有总体推断区间，不人为补上误差线。|

森林图明确标为事后分析，保留中性复核、错误输入及正确建议控制的五个比较。没有删除反例或只展示最大改善。区间是逐项探索性区间，没有多重比较校正；稀疏事件的原主指标与本图的全单元错误率是不同指标。

## 重新生成

在仓库根目录运行：

```sh
Rscript Submission_Pack/visualize_results.R
Rscript Submission_Pack/prepare_artifacts.R
Rscript -e 'rmarkdown::render("Submission_Pack/report.Rmd", quiet=TRUE)'
```

图形在 `figures/`，森林图和组成图的精确数据在 `evidence/plotted_effects.csv` 与 `evidence/plotted_composition.csv`。PPT布局脚本读取R导出的 `evidence/visualization_data.json`，不重新计算实验统计。
