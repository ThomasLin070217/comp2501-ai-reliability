# R presentation figures

The four result figures in slides 11, 14, 15 and 16 are generated by `render_results.R`. No historical or fabricated values are included. Blank counts produce empty axes and “Awaiting new data”, not zero-height bars.

From this package's root directory, run:

```sh
Rscript R/render_results.R
```

Optional input and output paths:

```sh
Rscript R/render_results.R new_chart_counts.csv new_figures
```

Fill the `numerator` and `denominator` columns in `chart_data_template.csv`. Preserve identifiers and group names. Counts must be whole numbers, and a numerator cannot exceed its denominator. Supply both counts or leave both blank. A supplied denominator of zero is “not estimable”.

| Chart | Numerator | Denominator |
|---|---|---|
| baseline / error | Incorrect | Model-specific C + I + A |
| baseline / noncorrect | Incorrect + explicit abstention | Same model-specific N |
| overall / error | Incorrect in that condition | Same eligible initial/self/natural matched N |
| overall / noncorrect | Incorrect + explicit abstention | Same eligible matched N |
| correction / Corrected | Wrong-to-correct after natural cross-check | MiniMax initially wrong + actual DeepSeek correct subset S |
| correction / Eliminated | Wrong-to-correct + wrong-to-abstention | Same S |
| risk / peer | Initially correct receiver becomes incorrect | Eligible initially correct matched subset T |
| risk / human | Initially correct model becomes incorrect | Model-specific eligible matched subset T |

Natural self and natural peer use the same eligible natural wrong-peer subset. Constructed self and constructed peer use the same eligible constructed wrong-peer subset. These two subsets remain separate. MiniMax neutral/user use the same eligible MiniMax subset, and DeepSeek neutral/user use the same eligible DeepSeek subset. Self here always means the matching neutral self-check branch, never the model's overall self-check rate.

Error elimination includes abstention, so it does not mean all eliminated errors became correct answers. Technical failures and unscorable output are excluded transparently, not treated as abstention. True “information insufficient” conclusions can be correct answers and must not be automatically classified as abstention.

Four figures are exported as high-resolution PNG and PDF. `plotted_values.csv` records the supplied counts and calculated rates. Update images in the PPT and replace its pending summary sentences after receiving new results. Paired uncertainty and final conclusions require the underlying paired data and are not calculated from this aggregate plotting input alone.

The script uses base R graphics and built-in graphics devices. On macOS it uses Quartz. Other systems use Cairo. No extra R packages are required. Plot source remains editable in R; embedded slide figures are images, as requested.
