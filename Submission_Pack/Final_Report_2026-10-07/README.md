# COMP2501 evidence report

The four-page [presentation companion PDF](output/pdf/COMP2501_evidence_report_2026-10-07_v3_ALIGNED_RQs.pdf) uses the four research questions exactly as approved by the user, and summarizes their evidence and limits for LINYUNIAN and PAN ZHENGYU. The [report source](report.md) links to the public, protocol-separated tables and R analyses. The course handout specifies an in-class presentation and proposal; it does not separately require this PDF.

The [presentation notes](PRESENTATION_NOTES.md) were written for an earlier 30-slide deck. For the revised mathematics presentation, use the [28-slide v17 deck](../Math_Only_2026-10-07/output/COMP2501_presentation_REVISED_MATH_2026-10-07_v17_MEASURED_DENOMINATORS.pptx) and its embedded speaker notes. Its [PDF backup](../Math_Only_2026-10-07/output/COMP2501_presentation_REVISED_MATH_2026-10-07_v17_MEASURED_DENOMINATORS.pdf) has the same 28 slides.

`build_report_md.R` checks the current public denominators and the local R-audited aggregate release from the private revised mathematics bank before writing `report.md`. It does not publish the private bank. From the repository root, with the private aggregate release available at its documented local path, rebuild with:

```sh
Rscript Submission_Pack/Final_Report_2026-10-07/build_report_md.R
pandoc Submission_Pack/Final_Report_2026-10-07/report.md \
  --from markdown --pdf-engine=tectonic --toc \
  --resource-path=Submission_Pack/Final_Report_2026-10-07 \
  -o Submission_Pack/Final_Report_2026-10-07/output/pdf/COMP2501_evidence_report_2026-10-07_v3_ALIGNED_RQs.pdf
```

The two embedded bar charts are generated by R from the named scored tables. The PDF was rendered and visually checked at four pages on 7 October 2026. A reader without the private aggregate release can inspect the committed PDF and Markdown but cannot reproduce the private-bank portion from this public repository alone.
