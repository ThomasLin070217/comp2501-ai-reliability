## 1. 主要研究问题的证据尚不确定〔高优先级，已披露〕

自然跨模型检查相比自行复核，事实题为40/102错误降至35/102，即−4.90个百分点；95%题目聚类区间为[−16.19,+5.94]。区间允许改善，也允许变差。不能把观察到的方向说成已证实稳定有效，也不能反过来说已证明无效。

模型分层方向不同：DeepSeek −14.29、Kimi +20.59、MiniMax −21.21个百分点。这些是当前配置的探索性结果，不是模型能力排名。只有36道事实题、每模型一次新调用；573条返回不等于573道独立题目。

可保留的结论：**本轮观察到部分纠错，但自然cross-check的总体事实错误率收益仍不确定。** 受控误导条件下的−16.55个百分点不能替代这个自然流程的估计。

## 2. 数学部分主要测到了输出一致性，不能承担广泛的“逻辑能力提升”结论〔高优先级，已披露但展示仍需突出〕

A的37个完整单元：初答错10个，自查错2个，跨模型复核错0个。10个初答字段错误中8个的解释已经到达正确结果；自查修正了这8个。跨模型相对自查的直接补充证据是剩余两个加法错误被修正。

按解释结尾另做事后诊断，初答到跨模型的数学降幅从27.03缩至5.41个百分点。原字段评分应保留，不能看到结果后替换主评分；诊断说明不同指标测的是不同能力。

旧数学实验也有相同问题：16个初答字段错误中13个解释已算对。两批因此不能当作两次独立、广泛的逻辑能力验证。13个题目仅来自四个家族，且整数题对照缺失。三角形题自身已提醒检查条件能否同时成立，输出类别也列出了矛盾、信息不足等选项；这会提示受试模型，并非无提示复现原始陷阱题。

可保留的结论：**复核修正了字段与解释不一致，并在小样本中额外修复两个算术错误。** 不能称“数学逻辑能力提高27%”或“解决了AI最容易错的数学题”。

定位：[报告数学语义解释](../../Submission_Pack/report.Rmd#L95)、[逐条复核](../../Natural_Crosscheck/reports/ai_review_annotations.csv)、[数学题库](../../Natural_Crosscheck/protocol/questions.jsonl)。

## 3. 核验步骤与更强弃答提示一起变化，机制不能分开识别〔高优先级，需要更明确写进正文〕

结构化条件增加检查论据的步骤，也再次明确要求无法确定就弃答。中性组系统提示本来就允许弃答，因此不是从无到有，但结构化组多了一次直接强调。没有“只加强弃答提醒、不增加核验步骤”的对照组。

同一错误材料下C2→C3：错误377→258，正确162→141，弃答180→320；配对中144个错误转弃答，只有5个错误转正确，另有反向变化。数据支持整套提示减少错误输出，**不能拆解成逻辑核验本身的净效果**。也不能证明全部变化只由弃答提示造成。

建议正文直接补充：本实验比较的是核验与不确定性管理的组合提示，尚未分离两者贡献。未来要识别机制，需要中性／只加强弃答／只增加核验步骤／两者合并的对照；无需为当前课程展示临时补跑。

定位：[实际提示原文](../../Natural_Crosscheck/R/common.R#L9)、[原受控提示](../../Peer_Misleading_Study/study.py#L32)。

## 4. 错误率指标符合本项目目标，但不能单独代表答案质量或可依赖程度〔高优先级，已有说明，建议增加一个反例〕

用户定义的“正确和明确弃答都不算错”可以保留。问题不在于把弃答算成坏结果，而在于错误率一个数不能区分正确解决问题与谨慎不答。极端的全部弃答也会得到零错误率，却不提供正确答案。

最清晰的反例是同伴给出正确答案的C4→C5：

|指标|普通复核C4|结构化复核C5|
|---|---:|---:|
|错误／全部719单元|30.18%|25.45%|
|正确／全部719单元|49.10%（353）|26.84%（193）|
|弃答／全部719单元|20.72%（149）|47.71%（343）|
|错误／实际给出答案|38.07%（217/570）|48.67%（183/376）|

最后一行是选择了不同回答子集的描述指标，不能解释为同一批已回答题目的因果效应；但它说明，“总体少错”不保证“看到一个回答时更值得相信”。主指标应与正确率、弃答率一起讲，不能把1−错误率称为accuracy。

显式弃答也可能保留错误的背景断言，答案字段正确也不保证理由正确。现有全文语义复核是定向、非盲AI审查，并非所有解释逐句外部验证。不要求组员追加人工填表，但应保留这一测量边界。

定位：[本轮计数](outcome_counts.csv)、[已有回答子集效应](../../Peer_Misleading_Study/reports/interaction_posthoc/effects.csv)、[报告原文](../../Submission_Pack/report.Rmd#L170)。

## 5. 确实使用不同模型，但尚未证明“不同模型”是收益来源〔中优先级，已披露〕

A测的是：接收模型在自己的初答之外，看到另一个模型的初答和理由，随后由原接收模型作最终决定。没有第三位裁判，也没有多轮辩论。它贴近用户思路的一部分，但不是完整的双agent协作系统。

N1没有另一个独立答案，N2有。缺少同一模型独立生成第二答案的对照，所以收益可能来自增加独立候选答案、内容质量、额外计算或模型差异，无法拆开归因。不同模型也不能保证知识错误彼此独立。实际部署的总成本亦不同。

可保留的结论：**这套跨模型流程的结果如何**；不能说“我们证明异构模型优于同模型多次回答”。

## 6. 解析器确实漏掉有效答案，而且影响了后续采集〔中优先级，真实已知处理缺陷〕

A有四条ISO年月答案和一条LaTeX文字后面的数学JSON被冻结解析器漏掉。后者本来可以读出数学结论，但作为初答被判不可用，相关后续分支未采集。三条不可用初答合计导致15个分支跳过；不能靠事后修解析器把没采集的回答补回来。

应保留冻结主结果和另列的修复诊断；未来采集前修好解析。不同解析/完整单元规则也限制A、B/C和数学模块的直接横向比较。

定位：[敏感性表](../../Natural_Crosscheck/reports/review_sensitivity.csv)、[冻结解析器](../../Math_Supplement/R/common.R#L24)。

## 9. 外推范围和来源问题仍须保留〔中优先级，多数已披露〕

- 实际提示称“另一AI”，所以可以作为错误人机输入的模拟材料，不能给出真实人类提示影响的概率，也不能断言迎合心理机制。
- 事实题集中于困难日期问答，筛选还要求可构造合格同伴材料；A又复用已研究的题目。不能解释为普通用户所有任务的日常错误率。
- 推理模式关闭、单一温度、短答案/解释限制、无工具，属于明确的实验设置。不能代表推理模式、联网检索、计算器或完整协作skill的最佳表现。本轮日志结束标记正常，但这不消除设置上的外推限制。
- 原日期来源争议与A中新标记的题干/命名争议仍存在；排除敏感性支持主要受控方向，不证明剩余参考全部无误。
- 已按题目聚类保留模型和重复之间的依赖，这是正确处理；模型共享初答作为donor也在同题簇内。不能改按所有响应彼此独立计算更窄区间。现有区间为探索性、逐项区间，未调整多重比较。
- 核对[CoVe原论文](https://aclanthology.org/2024.findings-acl.212/)后，报告称本项目是简化提示而非完整CoVe复现是恰当的。[MathTrap附录表13](https://aclanthology.org/2024.emnlp-main.915.pdf)确实记录了无提示时等边三角形陷阱误答，并比较了提醒题目可能不合理的情况。本项目不能把该历史结果当成当前模型的单题错误率。OpenReview自纠错论文页面本轮被浏览器验证拦截，未据此新增文献结论。

## 建议用于答辩的结论

> 在本次选定题目与模型配置下，错误同伴建议可以增加错误输出。结构化提示可以降低这种条件下的错误回答率，主要伴随更多明确弃答，并可能牺牲正确回答。自然跨模型检查修复了部分错误，但总体事实错误率收益仍不确定。交叉检查不能作为完全相信最终答案的保证。

这不否定弃答的价值，也不要求推翻项目。提交前优先处理三个表达问题：明确核验与弃答提示的组合效应、突出数学证据的实际性质、让主图与主比较分母一致。独立新题、同模型对照、弃答提示消融及多次重复属于后续更强研究，不应为得到想要的结论临时追加筛选。
