# 精简两模型研究的样本量估算

2026-10-05：用户询问“大约要多少条数据能得到我们想要的结果”。这是规划估算，不预先保证交叉复核降错，也不以获得显著结果为停采条件。

建议预算内的起点为已有100事实题与41 CHAMP数学题，MiniMax、DeepSeek各两次独立重复。事实4条件（初答、自行复核、自然跨模型复核、固定错误建议）；数学3条件（前三者）。共1,600+492=2,092条目标回答。搜索往返HTTP请求与最终回答不是相同计数；异常/截断会减少可评分记录。此规模适合描述方法和模型的表现，不能保证检出小收益，数学部分应视为补充证据。

两次重复仍只对应一道不同题，同一道题的两个模型也相关。分析先按题平均，不能把2,092条回答当2,092个独立样本。可复用数据须按新协议另行核查，不为符合预期结果挑选记录。

R脚本给出一个**单个配对二元比较的数量级示例**：假定20%的独立题目在两个方法间出现“错误/非错误”状态变化，80%功效，双侧alpha=.05或.025。近似需要：15个百分点差异68/82题；10个百分点155/188题；5个百分点626/758题。alpha=.025示例与分别检验事实和数学的两个主要比较相对应。

这些是假设情景，不是使用联网实测参数得到的正式功效保证。我们的实际估计量按同题重复及两个模型平均，其方差与单个McNemar比较不同；题目内相关性、不同模型效果的异质性、格式缺失、真实错误率及多重比较均影响实际功效。数学若错误率很低，小幅绝对改善尤其难检出。不能把示例题数直接宣称为本项目最低必需样本量。

计算使用正态近似的双侧阈值起始公式，没有连续性修正；确切双侧功效或完整聚类设计需要相应计算/模拟。公式依据[Stata官方配对比例功效手册，第21页](https://www.stata.com/manuals/pss-2powerpairedproportions.pdf)，查询日期2026-10-05。`Rscript docs/sample-size-planning/calculate.R`生成两张表。

新增500元预算仍然有效，停止旧批次时已有记录估价62.39277元，另对一个未收到结果的在途调用保留2元；这些是保护估价，不是实际现金账单。不得为了跑满回答数或追求显著性超预算。当前旧批次已停止，新两模型采集未在本次估算中启动。
