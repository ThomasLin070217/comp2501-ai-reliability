# MiniMax 联网事实题补充测试

已完成100题。查看[中文结果](reports/结果说明.md)、[逐题答案](reports/answers.csv)及[错误率柱图](reports/error_rates.png)。原始评分：63正确、21错误、13弃答、3格式异常；60题实际搜索，40题未搜索。格式异常的AI语义复核与搜索污染敏感性单列。

用户授权（2026-10-05）：“假设我们允许他们联网呢？ 尤其是这个fact check 你简单做一百题的测试吧，用minimax。”

使用 Followup_Validation 已冻结的全部100道事实题，不按本轮表现选题。MiniMax-M3 经原 HKU 接口，每题发出一次启用原生 web_search 的回答请求；是否实际搜索以返回的工具记录为准。温度0.6、thinking disabled、768输出token与原事实调用设置保持一致。联网提示替换“不使用工具”，并要求优先可靠来源、避免基准答案列表，在简短理由中给出来源链接。

接口预检使用两道非正式问题。首次仅声明工具时模型没有搜索；第二次明确 tool_choice 后返回 server_tool_use 和 web_search_tool_result。因此正式轮固定请求搜索，并实际记录调用与搜索结果，而不依据模型自称判断是否联网。预检不纳入100题。

原题、顺序、提示、采集器及评分依赖在正式调用前冻结。原始响应和请求保存于 runs，搜索来源可追溯。只有传输无结果可有限重试，错误、弃答、格式异常、截断及未搜索均不重试。参考答案不发送给模型。

错误只指最终答案字段错误；正确、明确弃答、无法判分和接口失败分别报告。沿用冻结的日期判分，不把解释或引用自动视为真实。所有数据处理使用R。

与旧同题 MiniMax 的 N0（独立初答）及 N1（自行复核）作历史对照，旧重复先按题平均。新组每题仅一次；不是同期随机联网对照，也不是新的跨模型复核试验。搜索可能找到基准题目副本，须记录此污染风险。新旧对照只能支持这套流程和题目下的补充观察。

费用：HKU课程配额的现金单价未知，报告实际token及搜索调用数。另设40元保守token/搜索估价保护，不冒充真实账单，不扩大此前100元授权；费用算法与有限重试规则见 protocol/freeze.json。预检用量单列。

官方接口文档：[MiniMax Server Tools](https://platform.minimax.io/docs/guides/server-tools)。
