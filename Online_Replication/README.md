# Can We Trust AI More After Cross-Checking? — 自主联网复现

本轮按用户2026-10-05最新要求：**每个模型自行决定是否搜索、搜索什么**。正常提问，API开放供应商原生搜索工具；不要求搜索、不强制工具调用、不提供研究者预先找好的网页。没有搜索的回答也纳入结果。旧离线数据全部原地保留。

## 实验结构

三个模型仍为 DeepSeek V4 Pro、Kimi K2.6、MiniMax M3。各自独立初答，随后同一接收模型的不同分支平行复核。自然同伴为另外一个模型的本轮初答；两次重复轮换另外两个模型。不设第三裁判，不让后一个初答看到前一个模型答案。

| 内容 | 题数 | 计划新回答 |
|---|---:|---:|
| 自然流程：初答、自行复核、跨模型复核、结构化跨模型复核 | 100事实 + 41 CHAMP数学 | 3,384 |
| 事实题受控建议：错误答案、错误答案加解释、核验错误建议、正确建议及核验 | 同100事实题 | 3,000 |
| 不额外强调弃答的提示对照 | 上述36事实题子集 | 216 |
| 旧数学陷阱补充：初答及6个受控分支 | 13题 | 546 |
| **合计** | **154道不同题** | **7,146** |

三模型、每模型两次重复。重复的初答和自行复核由各模块共享，不虚增独立样本。事实C2对应旧W0，C3对应旧W2；只有W1需要另外采集。原120事实题中既有20道参考答案/题意争议题仍保留历史记录，不重新纳入主分析；排除源于本轮前的核查，不依本轮模型表现。旧开发集和被替代的小pilot保留历史，不重复消耗额度。完整映射见`protocol/migration_inventory.csv`。

人为指定的正确/错误建议沿用原冻结刺激材料。这些材料是操纵变量，不冒充本轮模型自然搜索的结果；自然交叉复核的donor则全部重新独立生成。

## 工具与提示

- DeepSeek：同一模型改用官方Anthropic兼容接口，注册原生`web_search_20250305`。
- MiniMax：沿用HKU课程Anthropic兼容接口，注册相同名称的供应商原生搜索工具。
- Kimi：官方Chat Completions接口注册`$web_search`内置工具。模型选择调用后，R按官方协议原样回传参数，由Kimi执行搜索；研究者不制定查询、不加工结果。
- 不设置强制`tool_choice`。初始用户消息仅为原题；原系统提示去掉“只用自身知识/禁止工具”，保留固定输出结构与基础弃答权限。结构化核验提示只用于原对应实验组，不加要求联网的句子。
- 保留接收模型初答时的工具历史进行后续对话。另一模型仅收到自己的问题与自己发起的搜索结果；作为donor被引用时传递其答案和理由。
- 原温度0.6、thinking disabled保留；事实最多768输出token，数学1536。Kimi最多4次HTTP往返；达到工具循环上限记技术不完整，不能当弃答。

接口预检使用正式题库以外的问题，没有要求搜索。三模型均实际自主搜索，随后保留搜索历史的复核对话也成功。DeepSeek/MiniMax返回可见搜索记录；Kimi可能只返回search_id与用量，来源可观察性不等同，不能声称三个模型均有完整可审查网页正文。

这是一项API系统实验，不等同于消费者网页聊天产品。供应商检索系统、接口变化、JSON输出限制均影响外推。数学允许模型搜索完整题目，因此结果不能单独归因于内在逻辑能力。

## 统计与数据质量

错误率为错误/(正确+错误+明确弃答)。弃答不算错，也不算正确；传输失败、截断、格式异常另外报告。保留原固定评分器，不按新结果修改答案标准。

同模型同题重复先平均，再按题平均，最后三模型等权平均。主要N2−N1在事实和CHAMP数学分别报告；只用同题、同模型、同重复的有效配对，另报告全部覆盖和缺失。按题联合bootstrap 5,000次，两个主要比较各97.5%区间；其他95%区间是探索性。不能只报告搜索过的子组来代替整体表现，搜索选择与错误率的相关性不能证明搜索的因果效果。

可见来源的基准答案副本风险需事后标注；不在运行时替模型修改查询或筛掉结果。Kimi不可见来源不得假记“无污染”。旧离线与新联网分别分析，历史差异不能隔离接口、时间与提示变化。未完成全量前只发布明确标注的进度结果。

## 预算、顺序与停止

用户授权原文：**“新增上限 ¥500，超出先停”**。旧累计74.87456元不计入新500元。当前采用输入20元/百万token、输出50元/百万token及搜索0.08元/次的保守保护估值；不是供应商账单，HKU现金价格未知。

撤回草案的两次检索预检0.44723元也计入预算。每次HTTP预留2元；到480元保护线前停止发出新请求，余20元缓冲处理单次用量不确定性。授权不等于承诺7,146条一定能在500元内跑完：若每题都像预检一样搜索，全量保守估价明显超预算。冻结顺序混合题型，先完成自然对照再完成受控分支；不会因答错或弃答重试，也不会按效果挑选继续的题目。

## 复现入口

在仓库根目录运行，环境变量提供三个API密钥。密钥不得进入仓库。

```sh
Rscript Online_Replication/R/test.R
Rscript Online_Replication/R/collect.R
Rscript Online_Replication/R/analyse.R
```

正式前冻结任务、提示构造、采集与分析代码及旧评分依赖。`runs/http`保存逐次请求与响应，`runs/completed.jsonl`保存最终回答，`reports`保存R表格和图。技术错误不自动重试。支持已收到响应的断点恢复；不重新生成已有错误或弃答回答。

已撤回的共享检索草案和两次预检单独保留在`abandoned_shared_retrieval`，不是正式结果。

官方接口依据：[DeepSeek原生搜索](https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/)、[Kimi内置联网搜索](https://platform.moonshot.cn/docs/guide/use-web-search)、[MiniMax Server Tools](https://platform.minimax.io/docs/guides/server-tools)，查询日期2026-10-05。
