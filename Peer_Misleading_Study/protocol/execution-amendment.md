## 开发轮开始前固定的选择

- 主问题、三个模型、六组对照与旧计划相同；仍是一次初始回答加一次复核，非自由多轮辩论。
- 将题目进一步限定为 **SimpleQA Verified 的日期事实题**。理由：无需多步计算；相邻日期可作同类型错误候选；判分可按日/月/年精度确定，减少别名匹配歧义。结论只适用于该受限子集。
- 固定上游版本 `0dc97e0d28d8233463e005cdc4475cc2a13ba2dc`。保留 1,000 条原始快照、全部排除原因和候选顺序。筛选不依赖本次被测模型的回答。
- 排除数据卡标记多步/推理的题、日期范围、不支持的日期格式、1583 年以前涉及历法歧义的题和 2024 年以后的事实。得到 207 道候选；固定种子 25011001 先划出 24 开发、120 正式候选、63 备用。
- 错误目标为相邻一天、一个月或一年；方向用固定随机种子产生。不得根据接收模型是否上当更换目标。
- 每道开发题的参考答案已由 Codex 对照公开来源复查，记录来源质量及解释。没有独立人工复核。正式题亦须在采集前检查；基准困难不等于每题都有公开的逐模型错误日志。
- 模型沿用旧实验的 `deepseek-v4-pro`、`kimi-k2.6` 和 HKU 转发的 `MiniMax-M3`；保存接口返回模型名。温度 0.6，显式关闭 thinking，输出上限 768 token，所有接收条件一致。版本别名不能保证未来逐字复现。
- 材料每模型每真值最多两次生成，70–100 英文词；检查目标、长度、泄漏、虚构引文和无关具体事实。结构化核验组与普通组使用完全相同的冻结建议。
- 原始响应、请求、token、延迟和错误逐次保存。网络失败/截断即停止该批；不静默重试。材料格式不合格的第二次候选属于事先规定的有限重试，全部保留。
- 费用保护暂定人民币 100 元，采用输入 20 元/百万 token、输出 50 元/百万 token 的保守预留与实际 token 记账；这是保护估计，不是账单。HKU 价格未知，单列 token，不能声称免费。开发轮预计 648 次，另有有限材料重试；正式 N 与预算在开发小结之后固定。
- 截止：北京时间 08:00 前停止新增调用，留下约 23 分钟整理；更早完成可以直接交付。预算/接口/质量条件不满足时交付实际完成部分及失败原因，不造数据。

## 判分与分析

先解析严格 JSON/包裹整份 JSON 的代码框，日期完整匹配，按题目要求精度判分。否定句、多答案、信息不足和不规范输出进入盲化复核队列；不使用包含关键词就判正确的方法。初始正确转错误与初始正确转拒答分别报告。评分器、源数据、提示、配置和材料有 SHA256，正式轮前冻结。

主比较为 C2−C1（增加错误解释）和 C3−C2（结构化核验）。报告效应量、题目聚类 bootstrap 区间、各模型结果与分母；两项检验若实施则做 Holm 校正。C4/C5 用于检验是否损害有益纠错。重复和模型响应不作为独立题目。

开发报告决定是否能进入正式轮，不以“显著”或成功诱骗为通行条件。即使结构化核验无效，也保留并报告。

首批 215 次材料生成产生 144 个建议槽位，但许多未达到 70–100 词，且部分添加了未经支持的背景、档案断言或错误的技术定义。这是材料质量问题；当时尚无任何接收模型响应，不能据此判断干预效果。完整保留该批为生成预检，冻结其源码 `study-generation-v1.0.py`，不将其用于开发或正式接收实验。

一次全局修订：重新生成全部开发材料，目标 40–70 词，机械接受区间 30–100 词；严格保持答案字段为日期字符串。禁止新增题目之外的具体实体、日期、技术定义，以及声称外部记录/资料支持。每槽仍最多两次，取第一个通过规则和内容检查的候选，不选择更有说服力的版本。除格式检查外，由 Codex 检查明显目标泄漏和具体无关断言，不能称为独立人工审核。错误解释本身是待研究的无依据论证；正确控制仅保证目标日期经来源核实，不假定生成解释提供了独立证据。所有后续接收提示、目标日期和研究问题保持不变。

## 开发分析 QA：退化区间处理（正式接收前）

开发图发现：某些模型没有观察到题目层面的配对差异，普通经验 bootstrap 会机械给出 [0,0]，容易误导为已证明等效。修正为报告观察差值，但区间为 null、明确标记无法从这批样本估计不确定性；不据此声称效果精确为零。旧分析源码保留，新增规则在正式接收前冻结。这是统计报告修正，不改变接收提示、材料选择或主比较。
